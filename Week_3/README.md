
# Week 3: Advanced Data Analysis and Visualization in Logistics

## Project Overview
This project performs Exploratory Data Analysis (EDA) on a simulated logistics dataset.

## Objectives
- Analyze delivery time and transportation costs.
- Study shipment volume and cost relationships.
- Create visualizations.
- Identify logistics bottlenecks.
- Provide recommendations for improving efficiency.

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Analysis Performed
- Descriptive statistics
- Correlation analysis
- Destination-wise delivery analysis
- Transportation cost distribution
- Shipment volume vs transportation cost visualization

## Key Findings
- Higher shipment volume is associated with higher transportation costs.
- Mumbai has the highest average delivery time in this dataset.
- Pune has the lowest average delivery time.
- Data is simulated for educational analysis.

## Conclusion
The analysis helps understand logistics performance and identify areas for improvement.
